Método de Eulererror global O(h)
xn+1 = xn + h
yn+1 = yn + h · f(xn, yn)

Avanza en línea recta con la pendiente del punto actual. Es simple, pero acumula error si h es grande (Zill, secciones 2.6 y 9.1).

Runge-Kutta clásico (RK4)error global O(h⁴)
k1 = f(xn, yn)
k2 = f(xn + h2, yn + h2k1)
k3 = f(xn + h2, yn + h2k2)
k4 = f(xn + h, yn + h·k3)
yn+1 = yn + h6(k1 + 2k2 + 2k3 + k4)

Promedia cuatro pendientes dentro de [xn, xn + h] con pesos 1, 2, 2, 1 (Zill, sección 9.2).
